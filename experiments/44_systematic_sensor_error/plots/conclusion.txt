Experiment 44: Systematic Sensor Error
=======================================
NOT YET RUN

Motivation:
-----------
In exp 40 (and earlier), sensor error was sampled independently per obstacle.
With 3 obstacles, the effective error averages out (CLT-like), weakening the
gradient signal for phi. A real sensor has a systematic calibration bias that
affects all measurements, plus small per-measurement jitter.

This experiment uses a realistic two-level sensor error model to create a
coherent signal: some episodes the sensor is badly off on everything (phi
should be high), others it's accurate (phi can be low).

Setup:
------
- Action: [kx, ky, alpha, phi] — full ISSf-CBF
- Sensor error = systematic_bias + jitter
  - systematic_bias: U(-0.6, 0.4), sampled ONCE per episode (all obstacles)
  - jitter: U(-0.2, 0.2), sampled per obstacle
  - Handles general uncertainty (both under- and overestimation)
- Dynamics bias: U(0.3, 1.0), random angle, constant per episode
- Obstacle radius: U(3.0, 7.0), random per obstacle
- Training: 10M steps, 16 envs, standard reward

What we hope to find:
---------------------
1. Phi learning a stronger signal than exp 40, because the sensor error
   is now coherent across obstacles within an episode
2. Episodes with large negative sys_bias should push phi high
3. Episodes with positive sys_bias should allow phi to stay low
4. The policy learns to map perceived uncertainty to phi adaptively
