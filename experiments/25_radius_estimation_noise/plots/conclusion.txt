Experiment 25: Obstacle Radius Estimation Noise (Perception Uncertainty)
========================================================================

Question:
In the real world, robots don't know the true size of obstacles — they estimate
it from sensors (LiDAR, camera). If the robot UNDERESTIMATES the obstacle radius,
the CBF thinks it's safer than it really is. Does the ISSf-CBF's phi term learn
to compensate for this perception error?

Motivation:
- Previous experiments (18-22): disturbance was in the DYNAMICS (noise/bias on position)
  The CBF still computed h(x) with the correct obstacle radius.
- This experiment: disturbance is in the PERCEPTION (error in obstacle radius estimate)
  The CBF computes h(x) with a WRONG radius — this is what phi is theoretically for.
- Example: true radius=5.0, estimated=4.0, robot at distance 4.5 from center
  -> CBF thinks: h = 4.5^2 - 4.0^2 = 4.25 > 0 (safe!)
  -> Reality:    h = 4.5^2 - 5.0^2 = -4.75 < 0 (COLLISION!)
  -> The 1.0m radius gap creates a "danger zone" where the CBF is blind

Hypothesis:
  1. The standard CBF (alpha-only) will have safety violations because it trusts
     the underestimated radius and enters the danger zone
  2. The ISSf-CBF's phi term will learn to add extra margin (via the phi/h term)
     to compensate for radius uncertainty, keeping the robot further from obstacles
  3. Phi should show strong correlation with obstacle proximity — increasing near
     obstacles where the radius error is most dangerous
  4. This should be a more natural use case for phi than dynamics disturbance

Setup:
- Dynamic alpha+phi agent: [kx, ky, alpha, phi] action space (ISSf-CBF)
  - kx/ky in [-3, 3], alpha in [0.1, 5.0], phi in [0.01, 10.0]
- Dynamic alpha-only agent: [kx, ky, alpha] action space (standard CBF)
  - kx/ky in [-3, 3], alpha in [0.1, 5.0]
  - Both agents trained fresh with same radius noise model
- Noise model: OBSTACLE RADIUS ESTIMATION ERROR
  - TRUE radius = 5.0 (used for collision detection)
  - ESTIMATED radius = true + error (used in CBF h(x) and observation)
  - Training: error ~ U(-1.0, +1.0) per obstacle, sampled ONCE per episode
  - Eval hand-picked: error = -1.0 (worst case: thinks 4.0, true is 5.0)
  - Eval random: error ~ U(-1.0, 0.0) (always underestimate)
- NO dynamics disturbance (no bias, no noise on position)
- ISSf-CBF RHS: -alpha * h(x) + (||Lgh||^2 * phi) / max(h(x), 1e-4)
- Standard CBF RHS: -alpha * h(x)
- 3 obstacles, same slalom layout, 100m map, 2M PPO timesteps, 8 envs

Key difference from exp 22 (constant bias):
- Exp 22: uncertainty in DYNAMICS (position drift) — CBF sees correct h(x)
- Exp 25: uncertainty in PERCEPTION (radius estimate) — CBF sees WRONG h(x)
- This directly tests whether phi can compensate for model mismatch in h(x)
