Experiment 10: Alpha-Only Slalom
=================================

Question:
Can RL learn a dynamic alpha for the CBF constraint that outperforms any single
fixed alpha, even when the agent has no control over steering? The standard CBF
uses Lgh @ u >= -alpha * h(x) with a constant alpha, but a fixed alpha is a
compromise — too low and the robot is overly cautious (slow, gets stuck), too high
and safety margins shrink. Here, the agent ONLY controls alpha while a fixed
proportional controller handles steering (k_nom points toward target). This isolates
the question: is adaptive alpha alone enough to improve performance?

Setup:
- Dynamic agent: [alpha] action space only (alpha in [0.1, 5.0])
- Steering: fixed proportional go-to-goal controller (k_nom = 3.0 * dir_to_target)
- Baselines: fixed alpha = [0.1, 0.5, 1.0, 5.0] with same proportional steering
- 3 obstacles in slalom pattern, single-integrator dynamics
- 2M PPO timesteps, 8 parallel envs

Observations:
- Combined Scenarios (8 hand-picked):
  - The dynamic alpha agent successfully navigates all 8 slalom configurations.
  - Alpha clearly spikes near each obstacle (purple curves in col 3), showing the
    agent learned to tighten the CBF constraint on approach and relax it in open space.
  - Speed dips correspond to alpha spikes — the CBF is actively modifying the
    nominal control near obstacles, then releasing for full speed in between.
  - Policy maps (col 5) show a strong inverse relationship between alpha and
    distance to nearest obstacle. Near-contact alpha values reach 3-5, while
    far-away values settle around 0.5-1.0.
  - Fixed alpha baselines all follow roughly the same trajectory shape but with
    different speed profiles — low alpha is uniformly slow, high alpha cuts corners.

- Aggregate Metrics (100 random scenarios):
  - Target Reached: alpha=0.1 only 21%, alpha=0.5/1.0/5.0 and Dynamic all ~100%.
  - Safety Violations: 0% across all methods — the CBF constraint holds regardless.
  - Safety Margin: Dynamic alpha ~0.56m, sits between alpha=0.5 (~1.5m) and
    alpha=5.0 (~0.56m). It trades margin for speed like the aggressive baselines.
  - Path Efficiency: Dynamic alpha ~0.99, near-optimal. Better than alpha=0.1 (0.95).
  - Episode Length: Dynamic alpha ~301 steps, among the fastest completions.
  - Average Speed: Dynamic alpha ~2.0 m/s, matching alpha=1.0 and alpha=5.0.

Conclusion:
Even with no steering control, the dynamic alpha agent learns a meaningful policy.
It adapts alpha per-obstacle, achieving the speed of aggressive baselines (alpha=5.0)
while maintaining reasonable safety margins. The 0% collision rate across all methods
confirms the CBF constraint works regardless of alpha, but dynamic alpha achieves the
best balance of speed, efficiency, and margin. Since the agent can only modulate
how aggressively the CBF intervenes (not where to go), this shows alpha alone is a
powerful lever for the safety-performance tradeoff.

alpha=0.1 is effectively useless — 21% success rate due to overly conservative
behavior causing timeouts/OOB. Not worth including in future baselines.

Future Steps:
- Give the agent steering control too [kx, ky, alpha] (exp 9) — does controlling
  both steering and alpha yield even better results?
- Add disturbance to dynamics (exp 13) — does dynamic alpha still adapt well with noise?
- Add a learnable phi term to the CBF via ISSf-CBF (exp 14) — can the agent learn
  an additional robustness margin on top of alpha?
- Combine phi + disturbance (exp 15) — does phi help compensate for model uncertainty?
