Experiment 9: Three-Obstacle Weave (Full Control)
==================================================

Question:
Can the RL agent learn to jointly control steering [kx, ky] AND alpha through a
3-obstacle slalom on a 100m course? This is the flagship experiment — the agent must
weave around obstacles at alternating y positions (positive, negative, positive),
requiring both intelligent navigation and per-obstacle alpha adaptation. This tests
whether the agent can coordinate steering and alpha in a complex, multi-obstacle
environment.

Setup:
- Dynamic agent: [kx, ky, alpha] action space (kx/ky in [-3, 3], alpha in [0.1, 5.0])
- Baselines: fixed alpha = [0.1, 0.5, 1.0, 5.0] with learned [kx, ky] steering
- 3 obstacles (radius=5.0 each) in slalom pattern:
  - Obs 1: x in [20,35], y in [+5, +8] (upper)
  - Obs 2: x in [45,60], y in [-8, -5] (lower)
  - Obs 3: x in [65,80], y in [+5, +8] (upper)
- Target at x=100, y in [-3,3], radius in [1.5,3.0]
- 100m map, single-integrator dynamics, 2M PPO timesteps, 8 parallel envs

Observations:
- Combined Scenarios (8 hand-picked):
  - Dynamic alpha successfully weaves through all 3 obstacles in every scenario.
  - Trajectories (col 1) show smooth S-shaped weaving paths, passing below obs 1,
    above obs 2, below obs 3, with alpha color varying along the path.
  - Robot speed (col 2) shows three distinct dips corresponding to each obstacle
    encounter, with full-speed cruising in between.
  - Alpha (col 3) shows three clear spikes — one per obstacle — demonstrating
    the agent learned per-obstacle alpha modulation on the 100m course.
  - Alpha-vs-distance (col 4) confirms strong inverse correlation: alpha rises
    as distance to nearest obstacle decreases.
  - Policy maps (col 5) show coherent alpha fields that match the obstacle geometry.

- Alpha Adaptation Details:
  - Three distinct alpha events are clearly visible in the time-series plots.
  - Alpha values range from ~0.5-1.0 in open space to ~3-5 near obstacles.
  - The spike timing precisely matches the closest-approach to each obstacle.
  - Between obstacles, alpha relaxes quickly, showing the agent doesn't carry
    unnecessary conservatism from one obstacle to the next.

- Aggregate Metrics (100 random scenarios):
  - Target Reached: alpha=0.1 21%, alpha=0.5/1.0/5.0 100%, Dynamic 100%.
  - Safety Violations: 0% across all methods.
  - Safety Margin: alpha=0.1 ~3.6m (very wide berth), alpha=0.5 ~1.70m,
    Dynamic ~1.43m, alpha=5.0 ~0.56m. Dynamic sits between moderate baselines.
  - Path Efficiency: all successful methods ~0.98, near-optimal.
  - Episode Length: Dynamic ~369 steps, alpha=5.0 ~301 steps, alpha=0.5 ~505 steps.
    Dynamic is faster than conservative baselines but slightly slower than alpha=5.0.
  - Average Speed: Dynamic ~2.01 m/s, alpha=5.0 ~2.20 m/s.

Conclusion:
The 3-obstacle weave is where dynamic alpha really shines structurally — three
distinct alpha adaptation events demonstrate genuine per-obstacle modulation. The
agent learned a coordinated steering + alpha strategy: weave efficiently while
raising alpha at each obstacle encounter for speed, then relaxing in open space.

alpha=0.1 is catastrophically bad here: only 21% success. The 100m course with 3
large obstacles means the CBF influence zones cover a huge portion of the path, and
low alpha causes the robot to crawl through all of them, leading to timeouts.

Dynamic alpha achieves a strong balance — 100% success, 0% collisions, good safety
margins (~1.43m), and near-optimal path efficiency. It doesn't quite match alpha=5.0's
raw speed, but it maintains a larger safety buffer. This is the first experiment
where dynamic alpha clearly differentiates from both conservative and aggressive
fixed baselines on multiple metrics simultaneously.

Future Steps:
