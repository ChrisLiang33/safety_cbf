Experiment 18: High-Noise Phi-CBF (ISSf-CBF Stress Test)
=========================================================

Question:
Does phi become essential under high disturbance? Experiments 14-15 showed phi stays
low because noise was too small (scale 0.05) — the standard CBF handled it fine with
0% collisions, making phi a "comfort margin" rather than a necessity. Here we crank
noise to 5-6x higher levels to stress-test the ISSf-CBF framework.

Hypothesis: at noise scale 0.3, the standard CBF (no phi) will start accumulating
safety violations because the disturbance can push the robot through the CBF barrier
between timesteps. The ISSf-CBF's phi term (||Lgh||^2 * phi / h(x)) should provide
the formal robustness margin needed to prevent these violations. We expect to see:
  1. Alpha-only agent (standard CBF): non-zero collision rate at high noise
  2. Alpha+phi agent (ISSf-CBF): 0% or near-0% collisions
  3. Phi visibly increases near obstacles — the agent learned phi is necessary
  4. Alpha decreases near obstacles while phi increases — the expected trade-off

Setup:
- Dynamic alpha+phi agent: [kx, ky, alpha, phi] action space (ISSf-CBF)
  - kx/ky in [-3, 3], alpha in [0.1, 5.0], phi in [0.01, 10.0]
- Dynamic alpha-only agent: [kx, ky, alpha] action space (standard CBF)
  - kx/ky in [-3, 3], alpha in [0.1, 5.0]
  - Both agents trained fresh in this experiment with same noise
- ISSf-CBF RHS: -alpha * h(x) + (||Lgh||^2 * phi) / max(h(x), 1e-4)
- Standard CBF RHS: -alpha * h(x)
- Training disturbance: uniform noise, scale domain-randomized [0.0, 0.5] per episode
  (5x higher than exp 15's [0.0, 0.1])
- Eval disturbance: noise scale = 0.3 (6x higher than exp 15's 0.05)
- Dynamics: robot_pos += safe_u * dt + noise * dt
- 3 obstacles (radius=5.0), same slalom layout as exps 9/13/14/15
- 100m map, single-integrator dynamics, 2M PPO timesteps, 8 parallel envs

Observations:
- Combined Scenarios (8 hand-picked, noise=0.3):
  Both agents navigate all scenarios successfully. Trajectories are visually similar.
  Phi values remain small/flat across most scenarios — not showing the dramatic spikes
  near obstacles that were hypothesized. Alpha profiles are comparable between agents.

- Alpha & Phi Adaptation:
  Alpha shows some adaptation near obstacles in both agents, but phi does not show
  the expected complementary increase. The phi term stays low, suggesting the agent
  learned it doesn't need large phi values even at this noise level.

- Aggregate Metrics (100 random scenarios, noise=0.3):
  - Target Reached: 100% (both) — no difference
  - Safety Violations: 0% (both) — hypothesis rejected, alpha-only handles noise=0.3
  - Safety Margin: alpha-only ~1.58m, alpha+phi ~1.38m (alpha-only slightly higher)
  - Path Efficiency: ~0.99 (both)
  - Episode Length: alpha-only ~310, alpha+phi ~323 (alpha+phi slightly slower)
  - Average Speed: alpha-only ~2.85, alpha+phi ~3.03

Conclusion:
The hypothesis that noise=0.3 would break the standard CBF was NOT confirmed. Both
agents achieve perfect safety and task completion. Surprisingly, the alpha-only agent
has a slightly *higher* safety margin (1.58 vs 1.38), suggesting the additional phi
parameter may actually be slightly counterproductive — the agent trades some safety
margin for speed (3.03 vs 2.85 m/s).

Why phi still doesn't matter at noise=0.3:
1. The CBF constraint itself is fundamentally robust — even without phi, the QP solver
   produces controls that maintain h(x) > 0. The noise (0.3 * dt) is small relative
   to the obstacle clearance the agent naturally maintains.
2. The 1/h(x) amplification in the ISSf term means even phi ≈ 0.01 creates a large
   corrective force near the boundary, so the agent never needs to learn large phi.
3. The reward structure incentivizes reaching the target quickly. Since phi isn't needed
   for safety, the agent keeps it minimal to avoid unnecessary conservatism.

Comparison to Exp 15 (low noise):
- Exp 15 noise: 0.05, Exp 18 noise: 0.3 (6x higher)
- Exp 15 safety margin: dynamic 1.64m vs standard CBF ~0.93m (77% larger)
- Exp 18 safety margin: alpha-only 1.58m vs alpha+phi 1.38m (alpha-only is higher!)
- Exp 15 collisions: 0% for all methods
- Exp 18 collisions: 0% for both methods — still no difference

Future Steps:
- Try MUCH higher noise (0.5-1.0) to actually break the standard CBF — current noise
  levels are still within alpha's handling capacity
- Consider modifying the environment to make CBF constraint violations more likely:
  tighter obstacle spacing, faster required speeds, higher-order dynamics
- Alternatively, reduce the obstacle radius or increase robot speed to shrink safety
  margins and make phi's contribution more critical
- Investigate whether the reward function needs to explicitly penalize low phi to
  encourage the agent to learn meaningful phi values
