Experiment 22: Constant Bias Disturbance (Sensor Bias Simulation)
===================================================================

Question:
In exps 18-19, i.i.d. per-timestep noise averages out over hundreds of steps (CLT),
so the CBF never faces a persistent directional force. Does a CONSTANT BIAS (sampled
once per episode) finally stress-test the CBF enough to make phi essential?

Motivation (accuracy vs precision analogy):
- Previous experiments: noise ~ U[-s, s] each timestep = LOW PRECISION, HIGH ACCURACY
  The robot wobbles but the mean displacement is ~0. Like bottom-left of a target diagram.
- This experiment: constant bias per episode = HIGH PRECISION, LOW ACCURACY
  The robot is pushed consistently in one direction. Like top-right of a target diagram.
  This does NOT average out — it's a persistent systematic error (sensor bias).

Hypothesis: with constant bias of magnitude 0.7:
  1. The standard CBF (alpha-only) will accumulate safety violations because the
     persistent drift systematically pushes the robot into obstacles
  2. The ISSf-CBF's phi term will learn to create a robustness margin that accounts
     for the persistent bias, preventing violations
  3. Phi will show meaningful values (not flat near 0.01) because the constant bias
     can't be ignored — it's always pushing in the same direction
  4. The difference between alpha+phi and alpha-only should be dramatic

Setup:
- Dynamic alpha+phi agent: [kx, ky, alpha, phi] action space (ISSf-CBF)
  - kx/ky in [-3, 3], alpha in [0.1, 5.0], phi in [0.01, 10.0]
- Dynamic alpha-only agent: [kx, ky, alpha] action space (standard CBF)
  - kx/ky in [-3, 3], alpha in [0.1, 5.0]
  - Both agents trained fresh in this experiment with same noise model
- Noise model: CONSTANT BIAS per episode
  - In reset(): sample random angle, compute bias = magnitude * [cos(angle), sin(angle)]
  - In step(): robot_pos += safe_u * dt + bias * dt (same bias every step!)
  - Training: bias magnitude domain-randomized ~ U(0.0, 1.0) per episode
  - Eval: bias magnitude = 0.7, hand-picked scenarios use upward bias (+y)
  - Random scenarios: random bias direction per scenario
- ISSf-CBF RHS: -alpha * h(x) + (||Lgh||^2 * phi) / max(h(x), 1e-4)
- Standard CBF RHS: -alpha * h(x)
- 3 obstacles (radius=5.0), same slalom layout as exps 9/13/14/15/18/19
- 100m map, single-integrator dynamics, 2M PPO timesteps, 8 parallel envs

Key difference from exp 19:
- Exp 19: noise ~ U[-0.7, 0.7] EVERY TIMESTEP (i.i.d.) → averages out
- Exp 22: bias sampled ONCE, magnitude 0.7, applied EVERY TIMESTEP → cumulative drift
- Over 300 steps: exp 19 net drift ~ 0, exp 22 net drift = 0.7 * 0.1 * 300 = 21m!

Observations:
- Combined Scenarios (8 hand-picked, constant bias magnitude=0.7, direction=up):
  Both agents struggle with worst-case upward bias (toward obstacles). Even the α+φ
  agent fails to reach the target in some hand-picked scenarios — the persistent
  upward push is severe enough to cause failures for both agents. The α+φ agent
  generally takes more direct paths when it succeeds, while α-only takes wider detours.

- Alpha & Phi Adaptation:
  The phi term shows adaptive behavior near obstacles, increasing when the persistent
  bias pushes the robot toward obstacle boundaries. Alpha adapts dynamically in both
  agents. The key difference is that phi provides a formal disturbance-aware margin,
  allowing α+φ to maintain tighter but still safe trajectories.

- Aggregate Metrics (100 random scenarios, bias magnitude=0.7, random directions):
  - Target Reached: α-only 92%, α+φ 100% — φ agent never fails to reach target
  - Safety Violations: 0% both — neither agent violates safety constraints
  - Safety Margin: α-only 2.06m, α+φ 1.51m — α-only is MORE conservative
  - Path Efficiency: α-only 0.68, α+φ 0.99 — dramatic efficiency gap
  - Episode Length: α-only 369, α+φ 326 — φ agent is faster
  - Average Speed: α-only 2.94, α+φ 3.04 — similar speeds

Conclusion:
The constant bias experiment reveals that the key advantage of the ISSf-CBF's phi term
is NOT preventing violations (both agents achieve 0%), but enabling PRECISE robustness
margins. Without phi, the standard CBF compensates for persistent disturbance by being
overly conservative — maintaining a 2.06m margin and taking inefficient paths (0.68
efficiency). This over-conservatism causes the α-only agent to fail reaching the target
in 8% of scenarios (likely getting stuck or timing out near obstacles).

The α+φ agent, with its formal disturbance margin via phi, can be LESS conservative
(1.51m margin) while still maintaining safety. On random bias directions this yields
near-perfect path efficiency (0.99) and 100% target success. However, on worst-case
hand-picked scenarios (bias pointing directly toward obstacles), even α+φ fails some
scenarios — phi helps but does not fully compensate for extreme persistent bias.

This is a meaningful result: the value of ISSf-CBF is not just safety (both are safe)
but the SAFETY-PERFORMANCE TRADEOFF. Phi enables the robot to be safe AND performant,
while the standard CBF must sacrifice performance for safety under persistent disturbance.

Comparison to Exp 18 (i.i.d. noise=0.3):
- Exp 18: 0% violations both, margins 1.58m vs 1.38m, both ~100% target reached
- Exp 22: 0% violations both, but 92% vs 100% target reached, 0.68 vs 0.99 efficiency
- The constant bias stress-tests the CBF far more than i.i.d. noise, revealing the
  performance gap that was invisible with noise that averages out.

Comparison to Exp 19 (i.i.d. noise=0.7):
- Exp 19: i.i.d. noise, Exp 22: constant bias (same magnitude 0.7)
- Exp 19: net drift ~ 0 (CLT), Exp 22: net drift = 0.7 * 0.1 * 300 = 21m
- The constant bias creates a qualitatively different challenge that reveals the
  true value of the phi term in maintaining performance under persistent disturbance.
